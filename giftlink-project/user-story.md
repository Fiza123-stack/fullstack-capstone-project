# User Story Template

**Title:**
_As a [type of user], I want [an action] so that [a benefit / a value]._

**Description:**
A short description of the user story and what it aims to achieve.

**Acceptance Criteria:**
1. [Criterion 1]
2. [Criterion 2]
3. [Criterion 3]

**Priority:** High / Medium / Low

**Story Points:** [Estimate]

**Notes:**
Additional notes, dependencies, or edge cases to consider.

---

## Example User Stories for GiftLink

1. As a user, I want to register for an account so that I can list items for giveaway.
2. As a user, I want to log in securely so that my account and listings are protected.
3. As a user, I want to view a list of available gift items so that I can browse what's on offer.
4. As a user, I want to view the details of a specific item so that I can decide if I want it.
5. As a user, I want to search for items by name so that I can quickly find what I need.
6. As a user, I want to filter items by category so that I can narrow down my search.
7. As a user, I want to edit my profile information so that my details stay up to date.
8. As a developer, I want the backend to connect to MongoDB reliably so that data persists correctly.
